# Phases

> Skeleton notes. See `PLAN.md` in the repository root for the full plan.

## Phase 0 — Foundation (current)

Project scaffolding only:

- Monorepo structure: `frontend/`, `backend/`, `docs/`
- Environment templates and `.gitignore`
- Frontend app shell that installs, builds and runs
- Backend folder architecture

**Explicitly not included:** business logic, authentication, database models, APIs,
calculations, PDF generation or form logic.

## Phase 1 — Routing & UI shell

Routing foundation, layouts and placeholder pages.

## Phase 2 — Backend foundation

App factory, configuration, database extension and the health endpoint.

## Phase 3+ — Business modules

Authentication, Dashboard, Clients, Quotations, Invoices, Payments, Settings,
Documents and PWA enhancements.
